# CV Maquetadora Web

Currículum responsive desarrollado en HTML5 y CSS3 aplicando CSS Grid, Flexbox y estructura semántica.

## Tecnologías

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Design
- BEM

## Características

- Diseño responsive
- Exportación optimizada para PDF
- Estructura semántica
- Layout con Grid y Flexbox
- Diseño minimalista orientado a frontend
